# FOLD — 折りかけの美術室

複雑な立体が一枚につながる紙へひらく作品として実装しました。[試作を開く](http://127.0.0.1:8766/fold.html)。`npm run start:fold` で専用のローカルサーバーを起動します。

- ブロックの人・ロボット・ねこ・家・ロケット・お城・立方体・四面体・八面体・十二面体の10種類。接合部分の内側の面を除き、外側の面だけを一つの折り目の木でつなぎます。頭や手足も、折っている途中から一枚の紙につながります。
- **100の立体コレクション**を追加。探査ロボット・枝の彫刻・尖塔の街・宇宙ステーション・結晶の群れ・積層トーテム・小さな恐竜・空中庭園・翼の船・山の神殿を各10点、固定シードの乱数で作りました。形状自体が異なる100点で、平面の重なり・閉じた表面・一枚のつながりを検査して選別済みです。一覧には実形状から作ったSVGのプレビューを表示します。
- 「ランダムに次へ」は100点を一巡するまで重複しません。「連続」は一つの作品を最後まで折り、完成形を見せてから次へ進みます。100点を見ると停止します。手動の形選び・折り操作で停止し、前の作品にも戻れます。仲間ごとの絞り込みも可能です。
- 「ことばで作る」は**生成モック**です。「赤い、背の高いロボット」などから、対応する形・色・背丈を読み取り、決定論的なレシピを組み立てます。任意の文章から未知の形状を生成するAIではありません。未対応の形を入力すると現在の作品を保持して案内します。
- 初期状態と形の切り替え時は、展開図から「ゆっくり折る」が自動再生されます。一工程は約1.15秒で、前後に短い間を置いて一つの折り目だけを動かし、枝の先から根元へ順に組み立てます。現在の折り目を赤く強調し、工程・場所・一緒に動く面数を表示。「一つ戻す／次の折り目」と左右キーで一工程ずつ進めたり戻したりできます。完成形と展開図では約2.2秒止まり、逆順にほどきます。画面非表示・ダイアログ表示中は進行を止めます。OSの「動きを減らす」が有効なら、自動再生はせず完成形を表示します。
- スライダーで展開図・折りかけ・組み立てを行き来できます。ドラッグで回転、スクロールで拡大。展開図はどれも一枚につながり、平面上で面同士が重なりません。実線は切る線、破線はつながった折り目を示します。途中の面同士の衝突や実際の紙の組み立てやすさは判定しません。
- 完成見本では、現在動く面を黄色で表示し、裏に隠れる部分の輪郭も破線で重ねます。見本を押すと拡大。一時停止中の「この折り目をもう一度」は、その工程だけを始めから再生して同じ折り目で止まります。完成後は最後の折り目を見直せます。「組み立て中」「ひらいています」「視点を移動中」で動作を区別します。
- 途中で別の面が同じ平面へ重なる場合は、紙面ごとの小さな深度差で描画の優先順位を固定します。半透明の重なりは共通の深度で安定して合成し、黄色の強調は追加の面を重ねず紙面のシェーダーで着色します。物理的な面同士の衝突回避は行いません。
- 見やすさを優先し、面同士に落ちる影をなくして床には淡い楕円の影だけを表示します。面の陰影は穏やかに、裏面は淡い青に統一。輪郭・折り目は画面上で太さを保ち、回転しない接続の破線は省略します。動く枝全体を薄く、付け根の面を強く色付けし、和紙で隠れた折り目は薄い赤の破線、見える折り目は太い赤実線にします。透ける紙では輪郭・折り目・側壁を弱めています。紙厚の側面は切断辺だけに外向きで描きます。
- カメラは「定点／フォーカス」の2択。定点は展開図から完成までを収める同じ位置・画角を保ちます。フォーカスは折り目を基準に斜めの候補方向を作り、曲がる2面が正面や真横に潰れない角度を優先します。その中で工程の開始・途中・終わりの遮蔽と視点の移動量を評価。位置・角度・画角を穏やかに移し、大きな移動中は折る進行を待たせます。ほかの部位による遮蔽を完全に解消するものではありません。手動で回転・拡大すると追従を保留し、「追従を再開」で戻れます。「向きだけ戻す」とRキーは折り具合を保ちます。描画では紙の固定側を保ち、静止後はWebGLの再描画を止めます。
- UIは模型と折る操作を左、作品選びと道具欄を右へ再編しました。前後の工程・主再生・スライダーは一か所に集め、紙と絵・生成モックは開閉できます。960px未満では模型を先に表示し、作品／紙と絵／ことばを下部シートから開きます。シートや一覧の表示中は折る進行と音を一時的に止めます。
- BGMとSEは外部素材を使わずWeb Audioで合成しています。64 bpmの柔らかい音色に、4つの和音と少しずつ変わる音・休符を重ねます。折り目の動きに同期して短い紙の擦れ音を鳴らし、その瞬間はBGMを控えめにします。「音 ON」から開始し、BGMと折る音は独立の音量スライダーで0〜100に設定できます。ページを隠すと停止。音の開始方法は[Web Audioの推奨事項](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)に沿っています。
- 選んだ作品（色・背丈を含む）、折り具合、再生/停止、カメラモード・手動視点、紙質、入力したことば、コレクションの閲覧履歴と絞り込みをlocalStorageへ自動保存し、再読み込みで復元します。音量も保存しますが音は毎回OFFで始めます。持ち込んだ絵はIndexedDBに最後の1枚を保存します。同じブラウザ・同じURLの保存領域を使い、壊れた記録や保存不可では既定状態へ戻ります。
- 「この絵をのせる」で色付き模型から絵の投影へ切り替えられます。「絵がつながる視点」で完成位置と投影方向へ戻ります。完成時の座標から各面のUVを計算するため、閉じると隣接面の絵が連続します。
- 和紙／透ける紙を切り替え、好きな折り具合をPNGとして保存できます。紙厚は薄い側面メッシュ、透けは半透明描画による近似です。
- 「絵を変える」から画像を持ち込み可能。アップロード画像はブラウザ内で処理・保存します。
- 初期の鶴は内蔵Imagegenで今回生成した素材です。画像は `dist/images/fold/crane.png`、生成プロンプトは `dist/images/fold/provenance.json` に保存しています。

その場の画像生成は `fold_server.py` の `/api/fold/generate` に実装しました。起動するシェルの `OPENAI_API_KEY` が設定済みなら入力を受け付け、[公式Image API](https://developers.openai.com/api/docs/guides/image-generation) の `gpt-image-2.5-flare` で生成します。APIキーはブラウザに送信しません。未設定時は未接続と表示し、生成ボタンを無効にします。現在の環境はキー未設定のため、実APIによる生成は未検証です。成功・失敗・重複リクエストはモックで検証しています。

```sh
npm run start:fold
npm run test:fold
```

幾何のテストでは基本10種類を101段階、コレクション100点を6段階で折り、折り目の接合・面の剛性・床との位置、平面での非重複、閉じた表面の辺とトポロジー、100点の形状の違い、接合部の内部面の除去を検証します。ブラウザでは100点の重複しない切り替え・連続再生・一覧の絞り込みに加え、モック生成・色と背丈・未対応入力・描画メモリの解放・スマホ幅を確認します。結果と画像は `qa/fold/`、調査用の状態は `window.__FOLD__.snapshot()` から参照できます。専用サーバーは `127.0.0.1:8766` のみで待ち受けます。

`dist/fold-topology.js` が凸立体の和集合の外側の面を作り、接合部の内部面を削除します。`fold-models.js` は凸面の抽出・重ならない展開経路の探索・折り目の回転、`fold-collection.js` は100点用の形状レシピを担当します。`node generate-fold-collection.mjs` で候補を検査・選別し、`fold-net-data.js` の100点の目録と折り目、各SVGを再生成します。保存した経路によりブラウザでは毎回探索し直しません。`fold-surfaces.js` は色と顔・窓などのテクスチャです。のりしろ・紙厚を考慮した衝突判定は未実装で、表示と折る過程を楽しむモックです。
